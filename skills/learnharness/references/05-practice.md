# 05 · 练习（practice）

练习不是"再做几道题"。练习是**在没有任何提示的情况下把知识提取出来**——这是唯一能让知识变得"叫得动"的机制。

## 为什么要另起会话

教学会话里，上下文里全是你刚讲过的内容。在那里出题，测的是**短期记忆 + 上下文线索**，不是提取能力。

所以练习要么是新 topic，要么是用户明确要求的独立会话。材料只来自**已经教过并通过检查的节点**。

## 一次一题，先写思路

出题 → 等他自己写"你的思路" → 再判。

不要一次给三道题（学生会挑会做的先做，其余跳过）。
不要在题面里给提示（那是提示阶梯的活）。

## 提示阶梯 R0–R5

学生卡住时，**一次只给一档**，给完再等。

| 档 | 给什么 | 例子 |
|---|---|---|
| R0 | 只指方向，不说内容 | "这题和你昨天学的那个性质有关" |
| R1 | 点出涉及的概念 | "想想 softmax 的归一化在做什么" |
| R2 | 指出该用哪条规则 | "用点积衡量相似度，然后归一化" |
| R3 | 给第一步 | "先算三个分数，再归一化" |
| R4 | 给大半 | 写出前两步的具体计算，留最后一步 |
| R5 | 给完整答案 | 只在学生明确要求、或已经连错两次后 |

**记录用了哪一档**（`rung` 字段）。同一道题用 R4 才做出来，等于没掌握，下一个节点要重教。

## 错因分类（决定下一题怎么出）

| 分类 | 含义 | 下一题 |
|---|---|---|
| `cue` | 线索不足：知识在，但没被触发 | 换一个不同的触发场景，考"叫得动" |
| `discrimination` | 概念混淆：把 A 当成 B | 出对照题：两个相似场景，只有一处不同 |
| `execution` | 会，但算错/写错 | 换一个更简单的数字，先验证流程 |
| `careless` | 粗心 | 不追，直接下一题 |
| `structural` | 概念缺口：根本没建立 | **停止练习，回教学**，把那个节点重讲 |

`structural` 是最重要的分类：练习中发现结构缺口，说明前面的检查漏了。这时候继续刷题是浪费。

## 检索型题面怎么写

| 差 | 好 |
|---|---|
| "softmax 的公式是什么？" | "给定 [3, 1, 0]，写出你算权重的第一步" |
| "多头的优点是什么？" | "如果你只有一个头，哪个任务会先崩？为什么" |
| "解释注意力机制" | "手算一个 2×2 的注意力输出" |

原则：**必须用到正确的知识才能做对，而题目本身不提示该用哪个知识。**

## 结论后暂停

学生给出答案、你判完之后：

1. 给判断（对/错/部分对）
2. 给错因分类（如果错）
3. **停。** 等学生说"下一题"再出。

不要自动连发。连发会让学生进入"刷题"心态，而练习的目的是提取，不是做完。

## 练习记录

每题的记录进 `log.jsonl`，关键字段：

- `outcome`：solved / solvedWithHints / movedOn / surrendered / dismissed
- `rung`：用到的最高提示档
- `missClass`：错因分类
- `retest`：是否要在下次会话重考

`retest: true` 的题，下次练习会话优先出。

## 什么时候练习够了

不是"做完 20 题"，而是：**同一知识在不同场景下、无提示地提取成功 2–3 次。**

到这一步才叫"会了"。在此之前都是"刚学会"。
